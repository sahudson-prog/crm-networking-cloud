# Backlog

Cada fila representa una idea, mejora o pendiente. El plan actual se arma seleccionando y ordenando items de este backlog.

## Estados

- Nuevo: idea capturada, aun no refinada.
- Refinado: entendida y lista para priorizar.
- Priorizado: entra al plan actual o proximo.
- En curso: se esta implementando.
- Hecho: implementado y validado.
- Pausado: valido, pero no se trabajara ahora.
- Descartado: no se hara por ahora.

## Prioridades

- P0: critico o bloqueante.
- P1: alto impacto / proximo ciclo.
- P2: importante, pero no inmediato.
- P3: idea futura.
