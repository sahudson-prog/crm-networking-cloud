# GAM-01 level illustrations

Original locally authored SVG artwork for Coffeecito. No third-party artwork,
downloads, fonts, external references or runtime services. All four share warm
colors, rounded dark contours, highlights and local gradients for volume.
Transparent backgrounds; viewBox 0 0 96 96.

- empty.svg: tilted empty cup and last drop.
- fire.svg: warm flame.
- rocket.svg: three-quarter rocket.
- radiation.svg: dimensional radiation emblem.

Static by design. UI supplies the level label; decorative images use empty alt.
These replace the earlier Lordicon proposal for this visual pass.
